## How I Built This

Mirage42 was built from scratch over **1,200 hours across 8 months**, with every hour tracked an the entire process documented publicly:

- 📊 **1,200 hours tracked on track.toggl** - the actual time investment, not an estimate.
- 📺 [**~220 daily build videos on YouTube**](https://www.youtube.com/@david_kingdom) - every coding session screen-recorded, 6-12 hours each.
- 📝 [**Daily project documentation on Google Drive**](https://drive.google.com/drive/folders/1h584KX_ducyfIwFz0EIE_QAz140hP7n2?usp=sharing) - planning notes, debugging logs, study material.
- 💻 **Daily commits on GitHub** - the contribution graph at the top of this  profile shows the rythm at a glance

**No AI-generated code.** Every line was written and understood, not pasted from a prompt.

- **Database & Services** - MongoDB Atlas, Cloudinary, Google OAuth
